# Decision Tree Machine Learning

A Machine Learning project that uses a Decision Tree Classifier to perform classification using Python and Scikit-learn.

## Project Overview

This project demonstrates how a Decision Tree algorithm can be implemented using Scikit-learn.

The project uses applicant information such as Age, Income, and Student status to predict whether a loan should be Approved or Denied.

The project includes:

- Dataset creation
- Data preparation
- Feature and target selection
- Decision Tree model training
- Prediction on new applicant data
- Decision Tree visualization

## Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Google Colab

## Algorithm

**Decision Tree Classifier**

The Decision Tree is configured using:

- Criterion: Entropy
- Maximum Depth: 3
- Random State: 42

## Input Features

The model uses the following features:

| Feature | Description |
|---|---|
| Age | Age of the applicant |
| Income | Annual income of the applicant |
| Student | Student status (1 = Yes, 0 = No) |

## Target

The target variable is:

**Loan Status**

- Approved
- Denied
